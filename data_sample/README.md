# data_sample

中文说明：
本目录存放新 `meta_bench` 样例任务使用的本地语料数据。当前包含 `med_papers/`，用于主流程样例任务的检索语料输入。

English:
This directory stores the local sample data used by the new `meta_bench` workflow. It currently includes `med_papers/`, which serves as the retrieval corpus for the sample task in the main pipeline.
